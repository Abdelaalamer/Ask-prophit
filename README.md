# إسأل النبي محمد ﷺ

تطبيق ويب خفيف يُثبَّت على الآيفون واللابتوب، يضم قاعدة معرفة مشروع «إسأل النبي محمد ﷺ»: السيرة والشمائل والأحاديث والآيات بدرجات ثبوتها، مع البحث وقائمة التحذير، وخاصية «اسأل» التي تجيب من منهجه ﷺ دون التكلم بلسانه.

- **التثبيت على الآيفون:** افتح الرابط في Safari، ثم زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».
- **التثبيت على اللابتوب:** افتحه في Chrome أو Edge، ثم «تثبيت التطبيق» من شريط العنوان.
- **«اسأل»:** يحتاج مفتاح Claude API يُدخل من شاشة «الإعداد». يُحفظ على الجهاز فقط ولا يُرفع إلى هذا المستودع.
- **من غير إنترنت:** القاعدة والبحث يعملان بعد أول فتح.

يُحدَّث المحتوى بعد كل دفعة بحثية. النسخة الحالية: حتى الدفعة 4.
